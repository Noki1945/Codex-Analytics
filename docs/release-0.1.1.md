# Codex Analytics 0.1.1 — альфа 2

Локальное расширение VS Code для анализа операций Codex и прогнозирования лимитов.

## Установка

Скачайте `codex-analytics-0.1.1.vsix` из вложений. В VS Code откройте **Расширения → … → Установить из VSIX**. Запустите команду **Codex Analytics: Open Dashboard**.

## Изменения

- Основное описание проекта и README переведены на русский язык; английская документация сохранена в README.en.md.
- Убрана жёлтая боковая полоска у примечаний. Текст ограничений сохранён.
- Темп расхода и вероятность исчерпания взвешиваются по длительности интервалов. Короткие интервалы больше не имеют такого же веса, как длинные.
- Прогноз исчерпания не строится по снимку старше пяти минут.
- Прогноз задач использует последние 100 подходящих наблюдений и исключает объёмы, отличающиеся от запрошенного более чем в четыре раза.
- Улучшена дедупликация: завершённое наблюдение не заменяется незавершённой копией. Проверка пересечений задач выполняется после сортировки, без полного попарного перебора.
- Проверяются целочисленность счётчиков токенов, размер кэша и корректность параметров прогноза.

## Ограничения альфа-версии

Проценты лимитов относятся ко всему аккаунту; активность других клиентов может влиять на измерения. Классификация операций основана на эвристиках. Прогноз требует минимум пяти подходящих наблюдений и не является гарантией. Промпты, код и ключи авторизации не сохраняются в аналитической базе. Для запроса лимитов может потребоваться полный путь к Codex в настройке `codexAnalytics.codexPath`.
