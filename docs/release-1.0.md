# Codex Analytics 1.0

Локальная аналитика Codex для VS Code.

График за 7 дней: синие пятичасовые столбцы и зелёная недельная линия; остатки лимитов, названия чатов, импорт архивов, фильтры, прогнозы, CSV/JSON.

Установка: скачайте codex-analytics-1.0.0.vsix, затем Расширения → … → Установить из VSIX.

Ограничения: данные могут быть неполными; пунктир соединяет неизвестные промежутки и сбросы; прогнозы эмпирические и не гарантируют результат. Версия 1.0 обозначает выпуск по запросу автора, а не подтверждение независимой проверки точности. Независимый проект, не официальный продукт OpenAI.
