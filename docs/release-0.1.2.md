# Codex Analytics 0.1.2 — альфа 3

## Точность прогнозов

- Диапазон расхода учитывает погрешность округления официальных процентов лимитов.
- Число доступных задач рассчитывается по верхней границе прогноза, а не только по медиане.
- Вероятность попадания в лимит сопровождается интервалом Уилсона для малой выборки.
- Проверка на более поздних задачах использует только ранее завершённые наблюдения. Показываются число проверок, средняя абсолютная ошибка и доля попаданий в диапазон.
- Остаток лимита для прогноза берётся из свежего снимка App Server; снимки старше пяти минут и истёкшие окна не используются.

## История и объём данных

- Завершённые задачи вынесены в отдельные строки SQLite; состояния импорта больше не содержат растущие массивы всей истории.
- Миграция сохраняет резервную копию прежней базы. Добавлена блокировка одновременной записи из нескольких окон.
- Ошибка отдельного журнала не прерывает импорт остальных файлов; подробности доступны в Output → Codex Analytics.
- История отображается страницами по 50 записей; сохранённая история доступна при отключённом автоимпорте.
- Синтетическая нагрузочная проверка 10 000 задач прошла локально. Это проверка хранения, а не доказательство качества прогнозов.

## Интерфейс и запуск

- Обновлены визуальная иерархия, карточки, узкий макет и график активности с подписями дат.
- Добавлен раздел качества наблюдений. Отсутствующие счётчики не подменяются нулями.
- Исправлено сообщение об отсутствии повторных действий: оно больше не предлагает импортировать уже загруженную историю.
- Добавлен поиск исполняемого файла в установленном расширении Codex и понятное сообщение при отсутствии CLI.

## Установка

Скачайте `codex-analytics-0.1.2.vsix`, выберите **Расширения → … → Установить из VSIX**. При предложении VS Code перезапустите расширения. Откройте **Codex Analytics: Open Dashboard**.

Это независимая альфа-версия. Предсказания остаются эмпирическими, измерения лимитов относятся к аккаунту. Сложность, размер проекта и будущие повторы пока не имеют обученных коэффициентов.
