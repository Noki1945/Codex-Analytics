# Codex Analytics 0.2 — бета 1

## Новые возможности

- **Импорт выбранной папки**: кнопка «Импорт папки» и команда `Codex Analytics: Import History Folder`. Можно добавить журналы из резервной копии или другого каталога, сохранив уже собранную историю.
- **Архивные сессии**: стандартный импорт также проверяет `~/.codex/archived_sessions`. Это отключается настройкой `codexAnalytics.includeArchived`. При явно заданном собственном пути автоматически читается только он.
- **Дополнительные фильтры**: операции и качество измерения пятичасового лимита.
- **Экспорт выбранных данных**: CSV и JSON учитывают текущие фильтры.
- **Сохранение состояния панели**: раздел, фильтры и введённые параметры форм сохраняются средствами webview VS Code. Финансовые параметры не попадают в аналитическую SQLite-базу.
- **Расчёты вне основного потока**: прогнозы, проверка на отложенной истории, нормализация и отчёты выполняются в рабочем потоке. Запросы и ответы сопоставляются по идентификаторам.
- **Единая выборка для прогноза**: выбранный период, операции и качество данных ограничивают историю, используемую калькулятором.

## Проверки

23 автоматических теста проходят локально. Добавлена интеграционная проверка нескольких источников, отсутствующего каталога, повторного импорта и запросов аналитики через рабочий поток. Проверены заполненный интерфейс, страницы истории, прогнозы и узкий макет. Бета остаётся предварительным выпуском.

## Установка

Скачайте `codex-analytics-0.2.0.vsix` ниже. В VS Code выберите **Расширения → … → Установить из VSIX**. Если предложен перезапуск расширений, выполните его. Затем **Ctrl+Shift+P → Codex Analytics: Open Dashboard**.

[Подробная инструкция на русском](https://github.com/Noki1945/Codex-Analytics/blob/main/START.ru.md).

## Ограничения

Проценты лимитов относятся ко всему аккаунту, классификация операций эвристическая, прогнозы требуют подходящей локальной истории и не являются гарантией. Сложность, размер проекта и будущие повторы пока не имеют обученных коэффициентов. Промпты, исходный код и ключи авторизации не сохраняются в аналитической базе. Полный набор агрегатов остаётся в памяти; неограниченные многогигабайтные архивы не проверены.
