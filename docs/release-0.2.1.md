# Codex Analytics 0.2.1 — бета 2

- На главной странице: текущие использованные и оставшиеся проценты обоих лимитов, время сброса и кнопка обновления.
- График 0–100%: пятичасовой лимит синим, недельный зелёным. Сбросы не соединяются линиями.
- Таблица наблюдаемого расхода по дням и день максимального наблюдаемого расхода. Пропуски, переходы суток и сбросы исключены; это нижняя оценка по имеющимся снимкам.
- Чаты показаны под названиями из локального session_index.jsonl. Названия читаются для отображения; промпты не импортируются.
- Счётчики чатов и ходов Codex разделены. Прежние «79 задач» означали 79 ходов внутри чатов, а не 79 отдельных пользовательских задач.

Установка: скачать `codex-analytics-0.2.1.vsix` → VS Code → Расширения → … → Установить из VSIX. Перезапустить расширения по предложению VS Code и открыть Codex Analytics: Open Dashboard.
